# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке. 

## 🚀 Функции и возможности
* **Математическое ядро "Dynamic Coarse-to-Fine" (v6.2.0):** Уникальный алгоритм сканирования динамически подстраивает размер сетки под размеры холста (вплоть до десятков метров). Это полностью исключает зависание процессора на крупных объектах и ускоряет поиск свободных слотов в тысячи раз.
* **Каскадное микро-скольжение:** Как только программа находит свободную ячейку, она включает алгоритм каскадного скольжения (от крупных шагов к мелким), прижимая фигуру к соседним объектам с финальной точностью вплоть до **0.5 миллиметра**. "Воздушные дыры" математически исключены.
* **Генетический алгоритм поиска:** Ядро программы использует эволюционную стратегию генерации последовательностей (скрещивание и мутация Топ-5 лучших проходов). Метод 1000 случайных переборов остался в прошлом, 40 вариантов гарантируют идеальный монолитный пазл.
* **Досрочная остановка:** Не обязательно ждать конца расчетов. Нажмите кнопку "ОСТАНОВИТЬ И ПРИМЕНИТЬ" в любой момент: программа мгновенно прервет потоки и расставит фигуры в CorelDRAW по лучшему из найденных вариантов.
* **Резервная зона для негабаритных фигур:** Фигуры, которые физически превышают площадь листа CorelDRAW, автоматически игнорируются при нестинге и безопасно выстраиваются в резервную колонку за правым краем документа.
* **Абсолютная независимость:** Программа скомпилирована в единый .exe файл со статической линковкой (/MT). 

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты.
2. Запустите файл CorelNester.exe.
3. Укажите отступ и лимит генераций. Для идеального результата достаточно **40-50 вариантов**.
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Наблюдайте за мельканием результатов в реальном времени. Нажмите кнопку **"ОСТАНОВИТЬ И ПРИМЕНИТЬ"** (внизу окна) — процесс мгновенно завершится.
6. Нажмите **"ЗАКРЫТЬ"**. Вариант компоновки уже применен к фигурам в CorelDRAW.

* **v6.0.0** — Тотальный рефакторинг математического ядра. Внедрен "Coarse-to-Fine BLF".
* **v4.6.0** — Внедрен Генетический Алгоритм поиска.
