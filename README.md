# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке. Алгоритм самостоятельно рассчитывает оптимальное расположение сотен деталей, экономя часы ручной работы и минимизируя отходы материалов.

## 🚀 Функции и возможности
* **Математическое ядро O(1):** Экстремально быстрый расчет десятков вариантов компоновки на базе модифицированного полигонального движка Clipper2. Сканирование ведется по контурам ("прыжками" через препятствия), что обеспечивает расчет 40 вариантов (поколений) за миллисекунды.
* **Абсолютная защита геометрии:** Плагин оперирует инвариантными центрами фигур. Искажения пропорций, размеров или непроизвольное смещение сгруппированных узлов математически исключены. Смещение выполняется через абсолютный векторный сдвиг Move(dx, dy).
* **Попиксельный контроль отступов:** Заданный отступ между объектами строго соблюдается вплоть до долей миллиметра без программных искажений (масштабирование 1:1).
* **Интеллектуальная защита от дубликатов:** Аппаратный контроль уникальности перестановок (std::set). Если все возможные уникальные варианты исчерпаны раньше заданного лимита, плагин досрочно завершает работу и мгновенно выдает наилучший результат.
* **Многопоточность:** Алгоритм автоматически масштабируется, задействуя доступные логические ядра процессора для параллельного просчета вариантов.
* **Pixel-Perfect UI:** Кастомный минималистичный Win32 интерфейс без стандартных системных рамок ОС Windows, аппаратно отрисованный векторный логотип через GDI+, полная интеграция закрытого шрифта **Azbuka**.
* **Абсолютная независимость:** Программа скомпилирована в единый .exe файл со статической линковкой (/MT). Не требует установки .NET Framework, VCRedist или сторонних тяжелых библиотек.

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты, которые необходимо скомпоновать.
2. Запустите файл CorelNester.exe.
3. В открывшемся окне плагина укажите:
   * **Размер отступа:** Желаемое расстояние между объектами в миллиметрах (например, 140).
   * **Количество вариантов:** Число попыток перестановки фигур алгоритмом для поиска варианта с наивысшей плотностью укладки (например, 40 или 100).
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Дождитесь завершения расчетов. В любой момент времени вы можете прервать расчеты нажатием на кнопку Х в шапке программы.
6. По завершении в логе появится сообщение ярко-оранжевого цвета === Компоновка успешно завершена ===, а также данные об общем размере получившегося полотна.
7. Нажмите **"OK"** для закрытия программы. Наилучший вариант компоновки уже применен к вашим фигурам в CorelDRAW.
