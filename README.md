# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке. Алгоритм самостоятельно рассчитывает оптимальное расположение сотен деталей, экономя часы ручной работы и минимизируя отходы материалов.

## 🚀 Функции и возможности
* **Математическое ядро "Min-Area Frontier" (v7.0.0):** Топовый алгоритм оценки координат. Программа сканирует только полезную рабочую область вокруг уже уложенных фигур (Frontier Bounds). Эвристика Min-Area жестко заставляет фигуры объединяться в минимально возможный квадратный кластер, математически запрещая растягивание деталей в линию вдоль страницы.
* **Строгий контроль лимитов:** Физические размеры страницы CorelDRAW строго соблюдаются. Если фигуре не хватает места, она переносится в резервную зону, не нарушая компоновку.
* **Микро-слайд 0.5 мм:** Для ускорения расчетов основной сканер "пробегает" поле с шагом 5 мм, а при нахождении свободного места активируется микро-сдвиг: фигура скользит влево и вниз с ювелирной точностью **0.5 миллиметра**, гарантируя полное прилегание контуров и отсутствие "воздушных просветов".
* **Генетический алгоритм поиска:** Ядро программы использует эволюционную стратегию генерации последовательностей (скрещивание и мутация Топ-5 лучших проходов). Это позволяет находить максимальную плотность укладки за минимальное количество попыток. 
* **Досрочная остановка и применение:** Нажмите кнопку "ОСТАНОВИТЬ И ПРИМЕНИТЬ" в любой момент: программа прервет фоновые потоки и мгновенно расставит фигуры по лучшему из найденных вариантов.
* **Абсолютная независимость:** Программа скомпилирована в единый .exe файл со статической линковкой (/MT). 

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты.
2. Запустите файл CorelNester.exe.
3. В открывшемся окне плагина укажите желаемый отступ и лимит генераций. Установите **100-200 вариантов**. Процессор с легкостью обработает их.
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Дождитесь завершения расчетов. Если вы видите, что алгоритм нашел отличный результат раньше времени, нажмите кнопку **"ОСТАНОВИТЬ И ПРИМЕНИТЬ"** (внизу окна) — процесс мгновенно завершится с сохранением лучшего варианта.
6. Нажмите **"ЗАКРЫТЬ"** для выхода из программы. 

## 📜 История версий (Краткая)
* **v7.0.0** — Мажорное обновление ядра. Внедрен алгоритм "Min-Area Frontier". Решена проблема зависания на гигантских страницах (45+ метров). Гарантировано формирование плотных квадратных кластеров без линейного вытягивания вдоль оси.
* **v6.1.0** — Возврат строгих ограничений физической страницы CorelDRAW. Не поместившиеся фигуры безопасно эвакуируются в резервную зону справа от холста. Добавлена кнопка умной досрочной остановки.
* **v6.0.0** — Тотальный рефакторинг математического ядра. Внедрен "Coarse-to-Fine BLF" (Быстрый сканер с локальным микро-слайдом до 0.5 мм). 
* **v5.0.0** — Переход на физику "Drop-and-Slide".
* **v4.6.0** — Внедрен Генетический Алгоритм поиска.
