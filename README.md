# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке. 

## 🚀 Функции и возможности
* **Математическое ядро "Compact Cluster Engine" (v12.0.0):** Тотальная эвристика площади (Min-Area). Алгоритм жестко запрограммирован избегать линейного вытягивания фигур в длину. Детали сжимаются в максимально плотный квадратный кластер у левого нижнего угла холста.
* **Coarse-to-Fine Adaptive Grid:** Алгоритм не "висит" на гигантских 45-метровых страницах. Он быстро находит пустоты вокруг уже уложенных деталей (фронтир) с шагом 10 мм, а затем активирует **микро-слайд** (сдвиг до 0.5 мм) для безупречно плотного соприкосновения сложной геометрии.
* **Разделение потоков (Защита интерфейса):** Математическому расчету присвоен самый низкий приоритет в Windows (THREAD_PRIORITY_LOWEST). Интерфейс программы больше никогда не будет "подвисать" (информация обновляется стабильно).
* **Генетический алгоритм поиска:** 40-50 поколений достаточно для достижения идеального монолитного результата благодаря скрещиванию и мутации лучших расстановок.
* **Атомарная досрочная остановка:** Кнопка "ОСТАНОВИТЬ И ПРИМЕНИТЬ" срабатывает мгновенно за счет глубокой интеграции прерывания Sleep(0) в цикл сканирования.
* **Абсолютная независимость:** Программа скомпилирована в единый .exe файл со статической линковкой (/MT). 

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты.
2. Запустите файл CorelNester.exe.
3. Укажите желаемый отступ и лимит генераций. Установите **100-200 вариантов**. Процессор с легкостью обработает их.
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Дождитесь завершения расчетов. Вы можете нажать кнопку **"ОСТАНОВИТЬ И ПРИМЕНИТЬ"** (внизу окна) в любую секунду — процесс мгновенно завершится с сохранением лучшего варианта.
6. Нажмите **"ЗАКРЫТЬ"**.
