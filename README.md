# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. 

## 🚀 Функции и возможности
* **Ультраскоростное ядро "True LBF Fast-Track" (v9.0.0):** Вместо просчета каждого миллиметра гигантского 45-метрового холста (что вызывало перегрузку ядер процессора и зависание интерфейса), алгоритм использует стратегию "Left-Bottom Fill до первого касания". Это гарантирует самую плотную укладку в левый нижний угол за доли миллисекунды.
* **Микро-слайд 0.5 мм (1 раз на деталь):** Теперь программа делает тяжелый, ювелирный микро-слайд только для идеальной найденной точки, а не для каждой пустой координаты. Это полностью разгружает процессор: 1000 проходов генерируются без зависаний за секунды.
* **Монолитный пазл без дыр:** Поскольку алгоритм всегда забирает самую левую точку (приоритет оси X), он физически не сможет вытянуть баннеры на 45 метров, пока не заполнит всю доступную высоту до потолка страницы. Результат всегда компактный.
* **Строгий контроль лимитов:** Физические размеры страницы CorelDRAW строго соблюдаются.
* **Атомарная досрочная остановка:** Кнопка "ОСТАНОВИТЬ И ПРИМЕНИТЬ" срабатывает мгновенно.

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты.
2. Запустите файл CorelNester.exe.
3. В открывшемся окне плагина укажите желаемый отступ и лимит генераций. Установите **100-200 вариантов**. Процессор с легкостью обработает их.
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Дождитесь завершения расчетов. Если вы видите, что алгоритм нашел отличный результат раньше времени, нажмите кнопку **"ОСТАНОВИТЬ И ПРИМЕНИТЬ"** (внизу окна) — процесс мгновенно завершится с сохранением лучшего варианта.
6. Нажмите **"ЗАКРЫТЬ"** для выхода из программы. 

## 📜 История версий (Краткая)
* **v9.0.0** — Мажорное обновление ядра. Внедрен "True LBF Fast-Track". Алгоритм находит самую плотную левую-нижнюю точку за долю миллисекунды. Проблема зависания процессора устранена математически. Гарантируется плотный квадратный кластер (без эффекта вытягивания в 45 метровую линию). 
* **v8.0.0** — Внедрен "Discrete-Edge Algorithm" (списан из-за образования пустот).
* **v7.0.0** — Внедрен алгоритм "Min-Area Frontier" (списан из-за перегрузки процессора микро-слайдами).
* **v6.1.0** — Возврат строгих ограничений физической страницы CorelDRAW. 
* **v6.0.0** — Внедрен "Coarse-to-Fine BLF".
