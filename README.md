# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке. 

## 🚀 Функции и возможности
* **Математическое ядро "Drop-and-Slide" (Новая Гравитационная Физика):** Ядро полностью переписано с нуля. Теперь фигуры физически "падают" сверху вниз, а затем "скользят" влево до упора, идеально заполняя вогнутости и пустоты между соседними элементами, как в Тетрисе. Алгоритм не оставляет пустых коридоров и разрывов.
* **Бинарная точность 0.1 мм и AABB-ускорение:** Скорость расчетов увеличена в сотни раз. Вместо тяжелого перебора сетки, точка столкновения вычисляется бинарным поиском (делением отрезка) с микроскопической точностью до 0.1 мм. Для идеального результата теперь достаточно всего 40 проходов алгоритма (генерация занимает секунды).
* **Генетический алгоритм поиска:** Ядро программы использует эволюционную стратегию генерации последовательностей. Первые проходы базируются на строгой геометрии (площадь, периметр), а последующие скрещивают и мутируют Топ-5 лучших вариантов.
* **Абсолютная защита геометрии:** Искажения пропорций, размеров или непроизвольное смещение сгруппированных узлов математически исключены.
* **Абсолютная независимость:** Скомпилировано в единый .exe файл. Не требует сторонних тяжелых библиотек.

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты.
2. Запустите файл CorelNester.exe.
3. В открывшемся окне плагина укажите желаемый отступ и лимит генераций. За счет генетического алгоритма и новой физики скольжения для идеального результата достаточно **40-50 вариантов**. (Не нужно ставить 1000).
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Дождитесь завершения расчетов. В любой момент времени вы можете прервать расчеты нажатием на кнопку Х в шапке программы.
6. Нажмите **"OK"** для закрытия программы. Наилучший вариант компоновки уже применен к вашим фигурам в CorelDRAW.
