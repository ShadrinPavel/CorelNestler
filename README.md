# Corel Nestler

![Corel Nestler Interface](screenshot.png)

## 📌 Описание программы
**Corel Nestler** — это профессиональный высокоскоростной плагин (написан на чистом C++ с использованием Win32 API) для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке. 

## 🚀 Функции и возможности
* **Ультраскоростное ядро "Adaptive Grid + Cascade Slide" (v10.0.0):** Вместо просчета каждого миллиметра гигантского холста (что вызывало перегрузку ядер процессора и зависание интерфейса), алгоритм генерирует "умную" дискретную сетку на основе размеров ваших деталей. Скорость поиска возросла в сотни тысяч раз.
* **Каскадный микро-слайд:** Фигуры соскальзывают в пустоты с ювелирной точностью до **0.5 миллиметра**, гарантируя монолитное прилегание без просветов. Нагрузка на ЦП сведена к минимуму.
* **Эвристика Компактности (Min-Area):** Алгоритм сжимает фигуры в минимальный плотный кластер, навсегда блокируя проблему растягивания объектов в 45-метровую "макаронину". 
* **Атомарная досрочная остановка:** Кнопка "ОСТАНОВИТЬ И ПРИМЕНИТЬ" срабатывает мгновенно.

## 📖 Руководство пользователя
1. Откройте ваш документ в **CorelDRAW** и выделите векторные объекты.
2. Запустите файл CorelNester.exe.
3. Укажите желаемый отступ и лимит генераций. За счет генетической оптимизации и сверхбыстрого алгоритма, **100-200 вариантов** пролетят за секунды и дадут идеальный результат.
4. Нажмите кнопку **"НАЧАТЬ КОМПОНОВКУ"**.
5. Дождитесь завершения расчетов. Вы можете нажать кнопку **"ОСТАНОВИТЬ И ПРИМЕНИТЬ"** (внизу окна) в любую секунду — процесс мгновенно завершится с сохранением лучшего варианта.
6. Нажмите **"ЗАКРЫТЬ"**.

## 📜 История версий (Краткая)
* **v10.0.0** — Мажорное обновление ядра. Внедрен "Adaptive Grid" для полного устранения зависаний UI на страницах размером более 40 метров. Введена эвристика Min-Area для плотной квадратной упаковки деталей. Кнопка СТОП встроена в ядро потока для моментальной реакции.

* **v6.1.0** — Возврат строгих ограничений физической страницы CorelDRAW. 
* **v6.0.0** — Внедрен "Coarse-to-Fine BLF".
