# Corel Nestler v4.3.1

**Corel Nestler** — это профессиональный высокоскоростной C++ плагин для автоматической, математически точной укладки (нестинга) объектов в CorelDRAW. Разработан для максимизации плотности размещения деталей при плоттерной и широкоформатной печати, а также фрезеровке.

## 🚀 Основные возможности

* **Эвристический алгоритм O(1):** Экстремально быстрый расчет сотен вариантов компоновки на базе движка Clipper2. Сканирование ведется по контурам (прыжками), что обеспечивает расчет 40 вариантов за миллисекунды.
* **Абсолютная защита геометрии:** При укладке плагин работает с инвариантным центром фигур. Искажения пропорций, размеров или смещение сгруппированных узлов математически невозможны. Объект переносится через векторный сдвиг Move(dx, dy).
* **Точный контроль отступов:** Заданный в интерфейсе отступ в миллиметрах соблюдается с попиксельной точностью без программных искажений (масштабирование 1:1).
* **Многопоточность:** Алгоритм автоматически задействует доступные ядра процессора для параллельного просчета вариантов перестановки.
* **Независимость:** Плагин написан на чистом C++ (Win32 API) со статической линковкой. Не требует установки .NET Framework или VCRedist. Работает на Windows 7, 8, 10, 11.
* **Pixel-Perfect UI:** Кастомный минималистичный интерфейс (без стандартных рамок ОС Windows), аппаратно отрисованный векторный логотип через GDI+, интеграция закрытого шрифта **Azbuka**.

## 🛠 Использование
1. Выделите нужные объекты в открытом документе CorelDRAW.
2. Запустите CorelNester.exe.
3. Укажите желаемый отступ (в миллиметрах) и количество вариантов (поколений) для просчета.
4. Нажмите "НАЧАТЬ КОМПОНОВКУ".
5. Плагин выберет самый плотный вариант и автоматически сгруппирует фигуры на листе, сохранив все объекты, вышедшие за пределы рабочей зоны, сбоку от листа.
