# История разработки Corel Nestler

## Версия 4.x.x (Релизная ветка)
* **v4.3.1** - Финализация интерфейса. Перевод таймера работы с миллисекунд обратно в классический формат ММ:СС.
* **v4.3.0** - Глубокая интеграция Win32 таймеров. Восстановление системных идентификаторов для асинхронного обновления логов интерфейса без блокировки основного потока.
* **v4.2.3** - Внедрение UpdateWindow. Интерфейс больше не "замирает" во время тяжелых транзакций COM с CorelDRAW. Добавлена оранжевая подсветка успешного завершения.
* **v4.2.0 - v4.2.2** - Фикс логирования. Плагин теперь отображает реальное количество уложенных внутри страницы объектов (исключая fallback-зону). Использование символа # вместо |.
* **v4.1.0** - Внедрение аппаратного парсера SVG для отрисовки логотипа "a" через кривые Безье GDI+. Внедрение защиты от дубликатов с помощью std::set. Перевод таймера на системный GetTickCount64().
* **v4.0.0** - Переход к конечным автоматам (State Machine) для контроля кнопок интерфейса. Возврат к стабильному "бульдозерному" ядру (Шаг 65). Искоренение старых системных имен шрифтов, полная интеграция семейства **Azbuka**.

## Версия 3.x.x (Ветка стабилизации геометрии)
* **v3.6.0 - v3.7.0** - Отказ от системных диалогов Windows. Полностью кастомное WS_POPUP окно (Pixel-perfect). Идеальные межстрочные интервалы.
* **v3.2.0 - v3.5.0** - Исправление бага с делением отступа пополам (1400 мм теперь равны 1400 мм). Защита пропорций деталей через трансляцию физических центров (исключены искажения ReferencePoint в Corel).
* **v3.1.0** - Внедрение "прыгающей" O(1) эвристики на базе библиотеки Clipper2. 

## Ранние этапы (1.x.x - 2.x.x)
* Миграция логики с медленного макроса VBA на высокоскоростной C++ исполняемый файл.
* Разработка алгоритмов генерации полигонов Безье для сложных кривых CorelDRAW.
* Подавление конфликтов макросов Windows API (windowsx.h vs VGCoreAuto.tlb).
* Реализация алгоритма "раздутия" контуров (InflatePaths) для обеспечения гарантированного зазора между деталями.
